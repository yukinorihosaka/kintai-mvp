# イベント・キッチンカー向け勤怠／シフト機能 仕様・実装計画（2026-10-23）

## 適用範囲
- 対象はタバジビエのキッチンカーおよび東京・近郊イベントのアルバイトスタッフ（約15人）。
- 丹波山村のジビエ処理施設および馬肉関連施設は対象外。
- 初期勤務地：タバジビエ五反田POPUP／青山ファーマーズマーケット／横浜赤レンガクリスマスゲート／キャナルフェス。
- イベント会場は管理者が追加でき、過去の会場を再利用できる。
- 1人1日1勤務地。会社全体では同日複数勤務地を許可。GPS確認不要。

## シフト
- 管理者のみ作成・編集。勤務日、従業員、勤務地、開始時刻、終了時刻、予定休憩時間を日単位で設定。
- 1日分を指定した別の日に一括コピー。コピー後は編集可能。週コピーは不要。
- 管理者に月間カレンダー、スタッフ別表示、勤務地別配置表。日付から編集できる。
- 同じスタッフが同日に複数勤務地に登録されたり、予定時間が重複したりしないよう保存時に検証。
- 下書きと公開を分離し、公開前のシフトは従業員に非表示。
- 公開済みシフトの変更は対象者にアプリ内通知し、変更前後の情報を示す。
- スタッフは本人分のみ月間カレンダー表示。過去実績および登録済み将来月も参照できる。
- 月単位の「確認しました」ボタンを設け、管理者は確認済み・未確認・確認日時を把握できる。
- 公開済みの本人分シフトが変更された場合、対象者の当該月の確認状態を未確認へ戻す。

## 勤怠
- 打刻原本（出勤、退勤、休憩開始、休憩終了）をそのまま保存する。
- 予定と実績の出退勤差が15分以上の場合は要確認として管理者に表示。15分未満でも実時刻を保存。
- 管理者が差異を確認し、承認・必要な修正を行う。修正前後、操作者、日時、理由を監査履歴へ記録する。
- 従業員は打刻漏れ・間違いの修正を日時と理由（必須）を指定して申請できる。
- 管理者が承認・差し戻し。承認前は本人が取り消し・再申請可能。承認後は再申請。
- 月間実績カレンダー、日別実績、月間勤務日数・累計実働時間、申請状況をスタッフ本人に表示。
- 時給登録や給与見込み表示は今回不要。
- 実働時間を予定時刻へ一律自動補正しない。月次集計とfreee CSVへの反映ルールは検証し、安全に段階移行する。

## 開発順序
1. 現行公開GASとGitHubのコード一致確認、スプレッドシートのバックアップ、機密情報の非公開を確認。
2. 勤務地マスターとシフト情報の拡張。既存シフト表の読み取り互換性を維持。
3. 管理者カレンダー、日単位コピー、勤務地別ビュー、保存時重複検証。
4. 下書き／公開／通知／月単位確認。
5. 従業員カレンダー、月次実績、打刻修正申請／承認と監査履歴。
6. ダミーデータで既存打刻、月次計算、freee CSV、アクセス権限の回帰テスト。
7. 利用者の確認後、GASへ反映・デプロイを別途判断。
