# 勤怠管理 MVP

15名程度の利用を想定した、Googleスプレッドシート＋Apps Script製の無料勤怠管理アプリです。

## できること

- スマートフォンから出勤・退勤・休憩開始・休憩終了を打刻
- 日付・曜日ごとの時間シフト登録（日またぎ対応）
- 月次の勤務、残業、深夜、遅刻、早退集計
- freee人事労務の「freee形式」CSV出力
- 社員番号＋PINログイン、管理者権限

## 導入手順

1. Googleドライブで空のGoogleスプレッドシートを作ります。
2. スプレッドシートの「拡張機能」→「Apps Script」を開きます。
3. `Code.gs` の内容をスクリプト画面の同名ファイルへ貼り付けます。
4. HTMLファイル `Index` を追加し、`Index.html` の内容を貼り付けます。
5. プロジェクト設定でタイムゾーンを「東京」にします。
6. `setupSystem` 関数を一度実行して権限を許可します。
7. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。
8. 実行ユーザーは「自分」、アクセスできるユーザーは運用範囲に合わせて設定します。個人Googleアカウントで全員に公開する場合は「全員」を選択します。
9. 発行されたURLを従業員のスマートフォンへ共有します。

初期ログイン：社員番号 `ADMIN` / PIN `change-me-now`

ログイン後、スプレッドシートの「従業員」シートで管理者PINを変更してください。PIN欄はハッシュ値なので、変更はWeb画面から行う運用を推奨します。現版にはPIN変更画面がないため、最初の変更はApps Scriptエディタで `changePin('ADMIN', 'change-me-now', '新しいPIN')` を一度実行してください。

## freeeへの取り込み

1. 管理画面で対象月を選び、freee CSVを作成します。
2. freee人事労務で「勤怠」→「勤怠情報」→「一括更新」→「勤怠サマリー」を開きます。
3. インポート元に「freee形式」を選択してCSVを取り込みます。
4. 取り込み前に、締め日と社員番号が両システムで一致していることを確認します。

## 運用前に決めること

- 法定休日と所定休日の区別
- 日単位・週単位の時間外労働の計算方法
- 打刻忘れ、遅刻、早退、休憩漏れの修正ルール
- シフトをまたぐ勤務と深夜勤務の扱い
- 月次締め後の修正手順

## 初期版の制限

- 申請・承認と通知は未実装です。
- 月次締めによる編集ロックは未実装です。
- 法定内残業は0として出力します。週40時間超など、勤務制度に応じた厳密な法定時間外判定は次段階で設定が必要です。
- 有休・欠勤は0として出力します。
- 同一日に複数回勤務するケースは、最初の出勤から最後の退勤までを集計します。
- Apps Scriptの公開範囲を「全員」にするとログイン画面自体は外部から到達できます。十分に長いPINを使用し、URLの共有範囲を限定してください。

給与計算へ使う前に、最低1か月は既存記録との並行運用を行い、社労士または給与担当者が集計結果を確認してください。
